Perimeter Widgets — Embed Lab

Each page below embeds widgets exactly the way a host site does. Pages without local in the name consume the repo's committed cdn/ — byte-for-byte what widgets.perimeter.org serves (loader → manifest → immutable bundle).

  • basic — the documented snippet, light theme
  • dark — data-theme="dark"
  • hostile-host — perimeter.org's measured host styles + aggressive global CSS; proves shadow isolation
  • theme-overrides — per-embed data-theme-* token overrides (brand color, radius, type scale, shadows)
  • canary — data-perimeter-version pin next to the manifest-resolved embed
  • narrow — 360px sidebar container
  • multi — two widgets, one loader (dedupe)
  • local — the NOT-yet-released local build from widgets/sermons/dist/ (build it first)
  • local-giving-history — the local build of my-giving-history in a 375px column, the width its long foundation names are most likely to break (auth-gated: needs a token in localStorage)

Widgets fetch live data from https://api.perimeter.org (the production API), so these pages need internet access. To target a local perimeter-api instead, add data-api-url="http://localhost:5500" to a placeholder div.
