Bypasses the loader and embeds /local/mission-trip-finder/index.js directly. Build first: pnpm --filter @perimeter/widget-mission-trip-finder build. data-api-url points at a local perimeter-api on :5500 — run pnpm dev there.

1 — the finder, with the detail opening in place

Click a card: it should fade to the trip's detail view without leaving the page, and the URL should gain ?trip-screen=detail&trip-id=…. Back returns to the grid. Inside the widget the cards must stay a plain grid (no bullets, no 2rem row gaps), banners and team avatars must have no red border and no grayscale, and buttons must stay brand blue rather than lime. On the detail, every team avatar must be visible — none stranded invisible. Both opt-in bands are off here, so the detail runs heading → About the Journey → Meet the Team with no photo scroller and no testimonials — that is the default, and it must look finished rather than gap-toothed.

1b — the default: cards link OUT (what a live embed still does)

No data-details-mode, so cards are anchors to the go-journey-details page, exactly as released 0.1.0 behaves. This is the release-safety default: publishing a new version must never change a live embed underneath us. Hover a card and check the status bar — it should show a perimeter.org/global-outreach/go-journey-details URL, and clicking must leave the page rather than opening the detail.

2 — pinned to one trip (what a details page embeds)

data-trip-id="958" renders that trip's detail alone: no grid behind it, no Back button, and the URL is never written to. This is the mode that replaces the widget on the WordPress go-journey-details page. It also opts into both bands: data-show-gallery="true" with five real banners in data-gallery-urls, and data-show-testimonials="true". Drag the scroller, or focus it and use the arrow keys. The cover photos must span the full page width — past this container's 90px padding, edge to edge — without introducing a horizontal scrollbar. Both bands are off by default (embed 1), because Global Outreach has no gallery photos and the testimonial quotes are still placeholder copy.
