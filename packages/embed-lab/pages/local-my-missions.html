Bypasses the loader and embeds /local/my-missions/index.js directly. Build first: pnpm --filter @perimeter/widget-my-missions build. data-api-url points at a local perimeter-api on :5500 — run pnpm dev there, on the branch that carries /api/missions/my-trips.

This is an authenticated widget, so it shows the sign-in prompt until an MP token is in localStorage. Two query params make it viewable without a real session: ?token=… seeds the gate, and ?apiUrl=… overrides the API origin. Point the latter at something that supplies auth for you — the studio's admin-gated impersonation proxy, or any local proxy that attaches x-api-key + x-on-behalf-of-user — and the widget renders that person's real data. Example: ?token=dev&apiUrl=http://localhost:5501

What must hold once trips render: the trip rows and Leaders strip stay a plain list (no square bullets, no 2rem row gaps); the donations table keeps its own thin border and full width rather than a red dashed 50%-wide box with hotpink centred-right cells; every button stays brand blue and square rather than lime with pill corners; the letter editor's contenteditable stays white-on-token in Sweet Sans Pro at its natural height, not yellow cursive at 40rem; bold text inside the letter and the description stays the widget's foreground colour, not red; and links stay brand blue without a strikethrough. Headings must not be uppercased. Every corner in the widget is square except the Leaders strip, which is round — and every glyph is Sweet Sans Pro, which this page loads for the document the way perimeter.org does.
