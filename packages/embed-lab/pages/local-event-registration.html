Bypasses the loader and embeds /local/event-registration/index.js directly. Build first: pnpm --filter @perimeter/widget-event-registration build. Open this page with ?id=<Event_ID> (a hidden test parent event) — the widget reads the event from the query string exactly as the native MP details widget does. Signed-out it shows the guest form; set localStorage['mpp-widgets_AuthToken'] (with mpp-widgets_ExpiresAfter in the future) to see the household roster. data-api-url points at a local perimeter-api on :5500, which must have the REGISTRATION_* guard configured for any submit — dry run included.
