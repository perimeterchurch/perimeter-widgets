# Pagination

Page navigation built from composable parts. You render the structure — a `Pagination` nav wrapping a `PaginationContent` list of `PaginationItem`s — and supply your own page numbers and `href`s. The links are anchors (built on Button), so wire them to your router or query-param state.

<Example label="Page navigation">
  <Pagination>
    <PaginationContent>
      <PaginationItem>
        <PaginationPrevious href="#" />
      </PaginationItem>
      <PaginationItem>
        <PaginationLink href="#">1</PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationLink href="#" isActive>
          2
        </PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationLink href="#">3</PaginationLink>
      </PaginationItem>
      <PaginationItem>
        <PaginationEllipsis />
      </PaginationItem>
      <PaginationItem>
        <PaginationNext href="#" />
      </PaginationItem>
    </PaginationContent>
  </Pagination>
</Example>

## Usage

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationPrevious,
  PaginationNext,
  PaginationEllipsis,
} from '@perimeter/ui/pagination';
```

Mark the current page with `isActive` on its `PaginationLink` (it renders the outline variant and sets `aria-current="page"`). Render `PaginationEllipsis` to stand in for skipped ranges. The Previous/Next labels are customizable via `text` and collapse to icon-only below the `sm` breakpoint.

## Parts

| Component            | Description                                                            |
| -------------------- | --------------------------------------------------------------------- |
| `Pagination`         | The `<nav aria-label="pagination">` wrapper.                          |
| `PaginationContent`  | The `<ul>` row of items.                                              |
| `PaginationItem`     | A single `<li>`.                                                      |
| `PaginationLink`     | A page link; `isActive` marks the current page.                       |
| `PaginationPrevious` | Previous-page link with a chevron and a `text` label.                 |
| `PaginationNext`     | Next-page link with a chevron and a `text` label.                     |
| `PaginationEllipsis` | A non-interactive "…" gap marker.                                     |
