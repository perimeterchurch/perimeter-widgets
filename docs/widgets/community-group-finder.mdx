# community-group-finder

A responsive card grid of **community groups**, with a filter panel above it.
Each card shows the group's neighborhood banner, its name, the city and state it
meets in, its meeting day and time, and an optional description, and links to
that group's group-details page. Groups at capacity are badged "Group Is Full".

Built to replace the stock Ministry Platform group-finder widget that
perimeter.org embedded previously. Unlike the other finder widgets there is no
legacy `reactwidgets` version — this is the first Perimeter-built one.

Groups are sorted by name and, by default, limited to groups published online in
Ministry Platform that have not ended.

## Embed

```html
<script src="https://widgets.perimeter.org/loader.js" async></script>
<div data-perimeter-widget="community-group-finder"></div>
```

Pin it to one neighborhood on a per-neighborhood page — this also hides the
Neighborhood filter, so a visitor cannot widen past the page they are on:

```html
<div data-perimeter-widget="community-group-finder" data-neighborhood-ids="5"></div>
```

## Filters

The panel mirrors the MP widget it replaces: a **Show/Hide Advanced** toggle over
Neighborhood, City or Postal Code, Group Focus, Life Stage, Meeting Days, and
Meeting Times, plus a keyword search box above it. While the panel is collapsed
the toggle carries a badge with the number of active filters (counted per filter,
so "Sunday + Monday" is one).

The dropdown options are **data-driven**, not hard-coded — they come from
`/api/community-groups/facets`, narrowed to values at least one visible group
actually uses, so the Neighborhood list never offers a neighborhood with zero
groups.

Values within one filter are OR-ed and separate filters are AND-ed: checking
Sunday and Monday widens the results, then picking a Life Stage narrows them.

**Meeting Times** are four buckets the API derives from MP's `Meeting_Time`
column: Morning (before 11:00), Lunchtime (11:00–13:59), Afternoon
(14:00–16:59), and Evening (17:00 onward). Evening is open-ended because most
community groups meet then. A group with no meeting time in MP — currently a bit
over half of them — never matches a Meeting Times filter.

**Meeting Days** covers Sunday through Saturday. MP also has a "Varying Day"
value, which has no place in a Su–Sa strip; those groups stay reachable through
every other filter.

**City or Postal Code** is one box for both: the city matches as a
case-insensitive substring, the postal code as a prefix, so `30005` still matches
MP's ZIP+4 values.

## Config

The widget reads its config from `data-*` attributes on the placeholder div.
`src/types.ts` holds the zod schema (the source of truth for options and
defaults).

| Attribute                | Type    | Default                                   | Description                                                                  |
| ------------------------ | ------- | ----------------------------------------- | ---------------------------------------------------------------------------- |
| `data-show-images`       | boolean | `true`                                    | Show the group's neighborhood banner on the card.                            |
| `data-show-description`  | boolean | `true`                                    | Show the group's description text on the card.                               |
| `data-description-limit` | number  | `260`                                     | Characters of description shown before truncating with an ellipsis.           |
| `data-show-filters`      | boolean | `true`                                    | Show the filter panel above the results.                                     |
| `data-show-search`       | boolean | `true`                                    | Show the keyword search box above the filters.                               |
| `data-advanced-open`     | boolean | `false`                                   | Start with the advanced filters expanded instead of collapsed.               |
| `data-hide-full`         | boolean | `false`                                   | Hide groups at capacity instead of badging them "Group Is Full".             |
| `data-group-type-id`     | number  | `13`                                      | MP Group Type. 13 = Community Group; 1, 3, and 10 are the other finder types. |
| `data-neighborhood-ids`  | string  | —                                         | Lock to one or more neighborhoods (comma-separated MP City Ministry IDs).     |
| `data-location`          | string  | —                                         | Preset the City or Postal Code box.                                          |
| `data-max-groups`        | number  | —                                         | Cap the total number of groups shown.                                        |
| `data-details-url-base`  | string  | perimeter.org group-details               | Base URL each card links to; the group ID is appended.                       |
| `data-details-label`     | string  | `See Details`                             | Label on the card link.                                                      |
| `data-empty-message`     | string  | `No community groups match your filters.` | Message shown when the list has no groups.                                   |
| `data-default-image-url` | string  | —                                         | Fallback banner URL for groups with no artwork in MP.                        |
| `data-api-url`           | string  | —                                         | Override the perimeter-api base URL (advanced).                              |

## Data source

`GET /api/community-groups` and `GET /api/community-groups/facets`
(perimeter-api). Each group is an MP `Groups` row of the configured
`Group_Type_ID`, joined to the lookups the filters use. See
`docs/domains/community-groups.md` in perimeter-api for the full mapping.

Two things worth knowing about the data:

- **"Neighborhood" is MP's `City_Ministries` table** (`Johns Creek`,
  `Alpharetta-Milton`, …), not `Congregations` or `Household_Parishes`.
- **Card banners are per-neighborhood, not per-group.** Every community group in
  a neighborhood has the same banner attached in MP and marked as its default
  image. Served by `GET /api/group-image/{id}`, which 404s when a group has no
  image; the card then falls back to `data-default-image-url` and finally to a
  plain muted band.

The card **never shows a street address.** `Groups.Offsite_Meeting_Address` is a
leader's home in nearly every case, so the API returns only the city and state —
the street line is never sent to the browser at all.

The **start date is shown only for groups that have not begun yet.**
Long-running groups carry a `Start_Date` from years ago (many are 2014), and
"Starts: Sun, Feb 9, 2014" on a card reads as stale data rather than information.

## Design notes

Styled after the mission-trip-finder: square corners throughout, no shadow on the
card or the "See Details" button, Sweet Sans (`font-sans`) for all text, and the
brand blue on the button. Deliberately **no decorative icons** — the
mission-trip-finder's pin/calendar/cost glyphs are absent here, and the fact
lines are plain text. The only glyphs are the affordances the form controls need:
the select chevron and the checkbox marks.
