# community-group-finder

A responsive card grid of **community groups** with a filter panel above it. Each
card shows the group's city banner, name, city and state, meeting day and time,
and an optional description, and links to that group's group-details page. Groups
at capacity are badged "Group Is Full".

Groups are sorted by name and, by default, limited to groups published online in
Ministry Platform that have not ended.

## Embed

```html
<script src="https://widgets.perimeter.org/loader.js" async></script>
<div data-perimeter-widget="community-group-finder"></div>
```

Pin it to one city on a per-city page — this also hides the City filter, so a
visitor cannot widen past the page they are on:

```html
<div data-perimeter-widget="community-group-finder" data-neighborhood-ids="5"></div>
```

## Config

Every option, with its description and default, is in the **Configure** panel
above — generated from `src/types.ts`, which is the source of truth.

## Data source

`GET /api/community-groups` and `GET /api/community-groups/facets`
(perimeter-api). Full mapping: `docs/domains/community-groups.md` there.

Four behaviours that surprise people, because you cannot see the reason from the
card:

- **Banners are per-city, not per-group.** Every group in a city shares one image
  in MP, so cards in the same city look identical. `GET /api/group-image/{id}`
  404s when a group has none; the card falls back to `data-default-image-url`,
  then to a plain muted band.
- **No street address, ever.** `Groups.Offsite_Meeting_Address` is a leader's home
  in nearly every case, so the API sends only city and state — the street line
  never reaches the browser.
- **Start dates show only for groups that have not begun.** Long-running groups
  carry a `Start_Date` from years ago (many are 2014), which reads as stale data
  rather than information.
- **Meeting Times are four buckets** the API derives from MP's `Meeting_Time`:
  Morning (before 11:00), Lunchtime (11:00–13:59), Afternoon (14:00–16:59),
  Evening (17:00 onward). A group with no meeting time in MP — currently over
  half of them — never matches this filter.
